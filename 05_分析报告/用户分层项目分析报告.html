09结论与局限

结论

  1. 两套分层都有效，但方式不同。规则 RFM 与 K-means 都能把人群按未来价值显著区分（Kruskal-Wallis p < 0.001），复购率与人均未来消费呈清晰单调排序。
  2. 分群没有超越基准。在相同选择人数下，「按历史金额排序」≥ 规则 RFM 与 K-means。分群不是更有效的预测工具。
  3. 分群的价值在于可解释与可运营。规则 RFM 把「连续金额」翻译成可直接驱动营销动作的语义标签，这是它真正的产出。
  4. K-means 的唯一实质增量在组内细分。核心高价值客户内部，落在簇0 的人均未来消费是落在簇1 的 倍（p < 0.0001）。
  5. 业务上「簇0」比「核心高价值」更高效。簇0 用 472 人覆盖 58.0% 的未来净消费，人均 4,481；核心高价值用 619 人覆盖 56.2%，人均 3,311。

局限（必须随结论一并报告）

  • 窗口不对称：历史 19 个月 vs 未来 5 个月，金额水平不可直接比较。
  • 小样本单元：「曾经忠诚」仅 20 人且未来净消费为负；交叉表存在 n<30 的单元，不可外推。
  • F 评分偏离标准口径：Shopify 三维均用分位数，本项目 F 使用固定频次分档（1→1, 2→2, 3-4→3, 5-8→4, ≥9→5），属业务化选择。
  • 同源特征：两种方法都用同一套历史 RFM 特征，交叉一致性不是独立验证。
  • 无干预验证：所有业务建议均为优先级假设，未经过增量实验。
  • 聚类边界重叠：轮廓系数 0.343 属中等水平，簇间存在重叠，不宜宣称「分得很开」。

后续可做

  • 补充特征：品类多样性、退货率、渠道来源、购买间隔趋势——这是突破 η² ≈ 0.33 上限的关键，瓶颈在特征而非模型。
  • 多切分点稳健性矩阵：2011-03-31 / 04-30 / 05-31 各跑一遍，检验结论在不同切分下的稳定性。
  • 监督模型（如 XGBoost）：建议在补齐上述特征之后再评估，否则边际收益有限。

关于 XGBoost 的范围说明

本项目聚焦「分层方法与分层有效性验证」，不包含监督式预测建模。 在仅有 R / F / M 三个特征、且其中 F 与 M 高度相关（Spearman ρ = 0.847）的条件下，监督模型的边际收益有限—— 瓶颈在特征，而非模型。若后续引入品类多样性、退货率、渠道来源、购买间隔趋势等特征，再评估监督模型才有意义。

④ 三条执行纪律

  • 不向高价值人群打折。核心高价值未来复购率 92.9%，他们本来就会买——发券只会侵蚀毛利。 对他们用身份权益（新品抢先、专属客服），对流失风险人群才用折扣。
  • 休眠客户只做一次自动化召回。1,507 人规模最大但价值最低，无响应就降频止损，不要反复触达伤害送达率。
  • 先提醒、后给券。流失风险与临近流失人群的召回序列应为「个性化提醒 → 无响应 → 再给限时权益」， 避免第一封就上折扣。
运营方案的适用边界：以上均为基于历史行为的优先级假设，不是已验证的因果效果。 「更可能消费」不等于「对触达反应更大」——真正的增量效果必须通过实际干预或 AB 实验验证。 上线前建议先在单一分层人群上做小规模实验，用对照组验证增量，再决定是否扩展到全量。
